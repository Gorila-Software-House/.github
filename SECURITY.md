# Política de Segurança

## Como reportar uma vulnerabilidade

Se você encontrou uma falha de segurança em qualquer projeto da Gorila Software House, **não abra uma issue pública**.

Envie um e-mail para **contato@gorilash.com.br** com o assunto "Segurança" contendo:

- descrição da vulnerabilidade e o impacto esperado;
- passos para reproduzir;
- versão, repositório ou URL afetada;
- sugestão de correção, se houver.

Confirmaremos o recebimento, avaliaremos o relato e manteremos você informado sobre a correção. Pedimos que a divulgação pública só ocorra após a correção estar disponível.
