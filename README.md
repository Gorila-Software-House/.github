# .github

Repositório especial da organização **Gorila Software House**. Ele é público e concentra:

- `profile/README.md`: perfil público da organização no GitHub.
- Arquivos de comunidade padrão (`CONTRIBUTING.md`, `SECURITY.md`), aplicados automaticamente a todo repositório da organização que não tenha o seu próprio.
- Templates padrão de issues (`.github/ISSUE_TEMPLATE/`) e de pull request (`.github/PULL_REQUEST_TEMPLATE.md`).

Não coloque neste repositório nada sensível: credenciais, dados de clientes, servidores ou informações internas.

Contato: [contato@gorilash.com.br](mailto:contato@gorilash.com.br)
