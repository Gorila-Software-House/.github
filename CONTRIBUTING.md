# Guia de Contribuição

1. Crie sua branch a partir da `main` (ex.: `feat/nome-curto`, `fix/nome-curto`).
2. Faça commits pequenos seguindo o [Conventional Commits](https://www.conventionalcommits.org/pt-br/), com a descrição em português: `feat: adiciona filtro por período`, `fix: corrige cálculo de juros`, `docs: atualiza README`.
3. Abra um Pull Request para a `main` preenchendo o template. Push direto na `main` não é permitido.
4. Garanta que os testes passam e que o PR foi revisado antes do merge.

Vulnerabilidades: veja [SECURITY.md](SECURITY.md). Não abra issue pública.
